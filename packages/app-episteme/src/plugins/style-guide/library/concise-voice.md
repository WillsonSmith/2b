Write tight. Cut every word that doesn't earn its place.

- Prefer short sentences. Break any sentence over 25 words into two.
- Lead with the point, then support it. Don't bury the conclusion.
- Delete filler: "very", "really", "just", "actually", "in order to", "the fact that".
- Use active verbs over nominalizations: "decide", not "make a decision".
- One idea per paragraph. If a paragraph runs past five sentences, split it.
- Read each sentence aloud. If you run out of breath, it's too long.
